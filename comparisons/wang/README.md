# Wang et al. comparison

This directory contains the scripts used for the uniform-concentration charge-conservation comparison.

## Files

### `reference_bvp.py`

High-accuracy 1D benchmark based on `scipy.integrate.solve_bvp`.

### `rfbnics_ucc.py`

RFBniCS implementation configured to reproduce the model and parameters used in the Wang et al. comparison.
