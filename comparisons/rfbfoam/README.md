# RfbFoam comparison

This directory contains the RFBniCS case used for the three-dimensional flow-through flow-field (FTFF) comparison with RfbFoam reported in the manuscript.

## Files

- `rfbnics_ftff.py`: RFBniCS implementation of the 3D FTFF comparison case.

## RfbFoam version

The original RfbFoam repository is available at:

https://github.com/mbarzegary/RfbFoam

The modified version used for this comparison is available in the `rfbnics-comparison` branch of the following public fork:

https://github.com/Ah-Aghabarari/RfbFoam/tree/rfbnics-comparison
